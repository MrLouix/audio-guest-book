    Trier depuis un PC

    Avec Google Drive pour ordinateur, les dossiers des messages et d'audio_src sont sur le disque du PC. Cette page peut s'y ouvrir sans copier le projet :

    1. Installer Python 3, puis une fois : python -m pip install flask numpy.
    2. Télécharger tri_messages.pyz et le poser dans le dossier qui contient les deux dossiers synchronisés.
    3. Le lancer (double-clic, ou python tri_messages.pyz) : la page s'ouvre dans le navigateur. Les choix redescendent ici à la synchro suivante.
