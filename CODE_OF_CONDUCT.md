# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/)
comme code de conduite.

En résumé : soyez respectueux et bienveillant, accueillez les points de vue
différents, critiquez les idées et non les personnes. Le harcèlement, les
propos discriminatoires et les attaques personnelles ne sont pas tolérés,
dans les issues, les pull requests comme dans tout autre espace du projet.

Pour signaler un comportement inacceptable, contactez le mainteneur
(@MrLouix) par un message privé sur GitHub. Les signalements sont traités de
manière confidentielle.
